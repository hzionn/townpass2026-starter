# 黑客松：時程與規則

整理自官網和工作坊資料（2026-11-07 讀取）。主辦單位保留修改權，有疑問時回官網確認，網址見 [links.md](links.md)。

## 題目

- 方向是「數位平權 × 友善共融」：從不同族群使用城市數位服務的情境出發，降低操作、理解與服務取得的門檻。
- 共 3 大類，細節 2026-11-07 當天公布。
- 目標固定：以台北通為基礎，開發城市通微服務新功能。

## 作品規則

- **Demo：** 只能投影實際運作畫面，禁用任何形式的簡報。不發表就失去評選資格。手冊寫模擬器也可以，但建議用實機，定位、掃碼、通知才能完整呈現。
- **資料：** 核心資料要用公開合法的開放資料，並註明來源；非必要資料可以用模擬資料。
- **第三方：** 只能用開源、免費的軟體，禁用商用套件（規則舉例 Google Maps），違反可能被扣分或取消資格。成果要能移轉、維運和上架。
- **AI：** 開發時可以用雲端 AI。作品執行時若有 LLM 的即時理解、推論或生成，必須完全在裝置端，不得呼叫任何遠端模型，也不得把使用者輸入傳到後端做 LLM 推論。登入、資料庫、檔案、排行榜、同步這類一般後端不受限。要揭露模型名稱、版本、量化格式、推論框架和來源，評審可能關閉網路並現場出題驗證。不得使用「危害國家資通安全產品」（含大陸廠牌）。
- **環境：** 自備電腦。主辦單位只提供電力和網路，沒有主機、資料庫或 AI 工具。
- **授權：** 成果以 AGPL 公開，一年內不得下架，不得侵害他人權利。得獎隊伍要在賽後協助整併進官方程式庫，完成後才核發獎金。
